# صنعة يد (San3at Yad)

## نبذة

صنعة يد هي منصة ليبية تربط العملاء بأصحاب المهن والحرف بطريقة سريعة وموثوقة.

يعتمد المشروع على عرض الحرفيين حسب المدينة والمهنة مع إمكانية الاتصال المباشر دون وسيط.

---

## أهداف المشروع

- دليل احترافي للحرفيين في ليبيا.
- سرعة الوصول للحرفي المناسب.
- واجهة بسيطة وسهلة.
- تصميم Mobile First.
- دعم اللغة العربية (RTL).
- قابلية التوسع لآلاف الحرفيين.
